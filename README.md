File Structure
composer.json - Defines the project dependencies (Africa's Talking PHP SDK)

composer.lock - Locks the exact versions of all dependencies

index.php - Main entry point for USSD requests

sms.php - Handles SMS functionality using Africa's Talking API

util.php - Contains configuration constants and utility values

Dependencies
The application requires:

PHP 7.1 or higher

Africa's Talking PHP SDK (v3.0.2)
